# Customer Shopping Behavior Analysis | Python, SQL & Power BI

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, and factors influencing buying decisions. It uses Python for data cleaning and exploratory data analysis (EDA), SQL for business analysis, and Power BI for interactive data visualization.

The objective is to transform raw customer data into meaningful insights that support data-driven business decisions, customer retention, and marketing strategy.

## 🎯 Project Objectives

* Understand customer purchasing patterns and preferences.
* Perform data cleaning and exploratory data analysis using Python.
* Analyze customer behavior using SQL queries.
* Build an interactive Power BI dashboard.
* Generate actionable business insights and recommendations.

## 📂 Dataset

The project uses a customer shopping behavior dataset containing information about customer demographics, product categories, purchase amounts, discounts, subscriptions, shipping preferences, and purchase history.

**Key attributes include:**

* Customer demographics, including age, gender, and location.
* Purchase details, including product category, purchase amount, and season.
* Customer preferences, including payment method and shipping type.
* Behavioral information, including previous purchases, discounts, and subscription status.

## ⚙️ How to Run the Project

### Prerequisites

Install Python and the required libraries. You will also need access to the SQL database used in the project and Power BI Desktop to open the dashboard.

### Step 1: Clone the Repository

```bash
git clone https://github.com/vlokesh2906/customer-trends-data-analysis-SQL-Python-PowerBI.git
cd customer-trends-data-analysis-SQL-Python-PowerBI
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter sqlalchemy
```

Install the appropriate database driver if your notebook connects to a SQL database.

### Step 3: Run the Python Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the cells in order to load, clean, and analyze the dataset.

### Step 4: Execute SQL Queries

* Create or connect to the database used by the project.
* Import the prepared dataset into the appropriate table.
* Open the SQL query file.
* Execute the queries using your database client.

Update the database connection settings to match your local environment.

### Step 5: Open the Power BI Dashboard

Open the `.pbix` file using Power BI Desktop. If prompted, update the data source and database connection settings before refreshing the report.

### Step 6: Review the Report and Presentation

Open the project report and presentation files to review the methodology, findings, and recommendations.
